# 메타데이터·시간축 인덱스 방법론

목표: 영상·음성 파이프라인의 **연산을 줄여주는 공짜 정보**를 최대한 회수하고,
모든 산출물이 정렬되는 **공통 시간축 인덱스**를 설계한다.

## 1. 컨테이너 메타데이터 추출

`ffprobe` 한 번으로 얻을 수 있는 정보를 파이프라인 계획에 활용한다.

- **기본 정보**: 길이, 해상도, fps, 코덱, 오디오 채널/샘플레이트
  → 처리 예산 산정, 다운스케일 비율 결정, 하드웨어 가속 경로 선택
- **챕터 정보**: 컨테이너에 챕터가 있으면(온라인 강의, 팟캐스트 등)
  씬 클러스터링 없이 **챕터 경계를 그대로 상위 계층 구조로 사용** — 연산 절약 + 정확한 의미 단위
- **키프레임(I-frame) 인덱스**: 코덱의 I-frame 위치는 장면 전환과 상관이 높음
  → 씬 검출의 초기 후보로 활용해 검출 비용 절감

## 2. 내장 자막·부가 트랙 활용 (STT 스킵 게이트)

- **내장 자막/CC 트랙**이 있으면 STT를 전부 또는 부분 스킵 가능 — 가장 큰 시간 절약 항목
  - 품질 검증: 자막 샘플 구간 몇 개만 STT로 교차 검증 후 신뢰 여부 결정
- 외부 소스 메타데이터(업로드 플랫폼의 설명·챕터 타임스탬프·태그)도 입력으로 받을 수 있게 설계

## 3. 공통 타임라인 스키마

세 파이프라인의 산출물이 **하나의 시간축**에 정렬되어야 검색·조립이 가능하다.

### 설계 원칙

- 모든 레코드는 `(start, end)` 구간과 `modality`, `type`을 갖는 **이벤트 단위**로 통일
- 원본 대용량 데이터(프레임 이미지, WAV)는 참조(경로)만 저장 — 인덱스는 가볍게 유지
- 증분 병합 가능: 2-pass 심화 분석 결과가 나중에 추가되어도 스키마 변경 없이 삽입

### 통합 이벤트 스키마

```json
{
  "id": "evt_00341",
  "start": 754.2,
  "end": 791.8,
  "modality": "video | audio | meta",
  "type": "scene | caption | ocr | transcript_turn | audio_event | chapter",
  "content": "…텍스트 표현…",
  "speaker": "SPK_2",
  "confidence": 0.93,
  "refs": { "keyframe": "scenes/012_01.jpg", "embedding": "vec/evt_00341" },
  "pass": 1
}
```

### 저장소 선택

| 저장소 | 용도 |
|---|---|
| JSON Lines | 파이프라인 간 중간 산출물 교환, 디버깅 용이 |
| SQLite (+FTS5) | 최종 타임라인 저장, 시간 범위 질의, 키워드 전문 검색 |
| 벡터 인덱스 (sqlite-vec, FAISS 등) | 씬 캡션·발화 턴 임베딩의 의미 검색 |

SQLite 단일 파일에 FTS + 벡터 확장을 함께 두면 로컬 환경에서 의존성 최소화 가능.

## 4. 파생 인덱스 (전처리 시점에 미리 구축)

질의 시점 비용을 전처리 시점으로 옮기는 장치들:

1. **키워드 역색인 (FTS)**: 전사문·캡션·OCR 전체 → 질의 키워드로 구간 즉시 검색
2. **임베딩 인덱스**: 씬 캡션 + 발화 턴 단위 임베딩 → 의미 기반 검색 (경량 로컬 임베딩 모델 사용)
3. **엔티티 테이블**: 캡션·전사에서 추출한 인물/객체/장소명 → 등장 구간 목록
   ("X가 언제 나왔어?" 류 질의를 LLM 호출 없이 1차 응답 가능)
4. **중요도 사전 점수**: 구간별 saliency 점수(시각 변화량, 발화 밀도, 오디오 이벤트, 챕터 시작 여부)를
   미리 계산해 컬럼으로 저장 → 질의 무관 요약 시 상위 구간 우선 선택

## 5. 시간축 정렬 시 주의점

- **기준 클록 통일**: 컨테이너 PTS 기준 초 단위 float 하나로 통일.
  가변 fps(VFR) 영상은 프레임 번호가 아닌 PTS로만 다뤄야 어긋나지 않음
- **오디오/비디오 시작 오프셋**: 트랙별 `start_time`이 다를 수 있음 — 디먹싱 시 보정
- **경계 불일치 허용**: 씬 경계와 발화 경계는 정확히 일치하지 않음 —
  병합 시 겹침(overlap) 기반 매칭을 사용하고 경계 스냅을 강제하지 않는다
